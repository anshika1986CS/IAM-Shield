
# IAMShield — AWS IAM Security Project

## About the Project

IAMShield is a beginner-friendly cloud security project focused on AWS Identity and Access Management (IAM). It explores how access permissions, authentication, and security monitoring can help protect cloud resources.

The project is being developed as part of a Cloud Security Engineer internship.

## Objectives

- Understand the AWS shared responsibility model.
- Learn the CIA triad: Confidentiality, Integrity, and Availability.
- Understand IAM users, roles, policies, and permissions.
- Apply the principle of least privilege.
- Explore secure authentication and credential management.
- Review common cloud security risks and their controls.
- Document security tests, findings, and recommendations.

## Security Practices

- Follow the principle of least privilege.
- Never upload passwords, secret access keys, or other credentials.
- Use official documentation when researching security concepts.
- Record actual test results separately from expected results.
- Do not claim a practical test was completed unless it was performed.
